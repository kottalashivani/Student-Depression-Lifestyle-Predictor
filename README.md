# Student Depression & Lifestyle Predictor

A classification model that predicts student depression risk from lifestyle, academic and demographic features.

**Tech stack:** Python, Pandas, NumPy, Scikit-learn

## Workflow
1. **Data cleaning & preprocessing** – handling missing values, encoding categorical features, feature scaling.
2. **Feature engineering** to prepare the dataset for modeling.
3. **Modeling** – train and evaluate classification models.
4. **Model selection** – compare models using classification metrics (accuracy, precision, recall, F1-score).
5. **Feature importance** – identify the lifestyle factors most correlated with depression risk.

## Setup

```bash
pip install -r requirements.txt

```
